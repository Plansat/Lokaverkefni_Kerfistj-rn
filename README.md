# Lokaverkefni_Kerfistjórn

Þetta verkefni fólst í því að setja upp notendur fyrir tölvufyrirtæki þar sem notendur eru í mismunandi hópum og hafa mismunandi réttindi á ákveðnar skrár.

Ásamt því að búa til heimasvæði fyrir alla. Með möppurnar Vinna og Leikir fyrir hvern notanda svo eru notendurnir líka með link möppurnar sem þeir hafa aðgang af.

Hægt er að finna upplýsingar um uppsetningu á notandanum Áslaug inn í leidbeiningar.md.
